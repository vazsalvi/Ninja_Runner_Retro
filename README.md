# 🥷 Ninja Runner Retro – 2D Endless Runner

**Ninja Runner Retro** is a fast-paced 2D endless runner game built using the **Godot Engine**. The player controls a retro-style ninja who must dodge obstacles, defeat enemies, and run as far as possible for a high score. Developed for a **Game Jam** and published on **Itch.io**.

## 🎮 Game Features

- 🏃‍♂️ Endless runner gameplay with increasing difficulty  
- 💥 Slide, jump, and slash enemies in real-time  
- ⚔️ Classic retro pixel art aesthetics  
- 📈 Score tracking and high score persistence  
- 🎧 8-bit background music and sound effects  
- 🧠 Basic enemy AI (patrolling and chasing)

---

## 🛠️ Technologies Used

- **Godot Engine**
- **GDScript / C#**
- **Aseprite / Piskel** (for pixel art assets)
- **Itch.io** (for game jam submission)

## ▶️ How to Play

- Open the project in **Godot Engine (v3.5 or v4)**  
- Load `Main.tscn` and hit **Play**
- Controls:
  - **Arrow keys / WASD** – Move
  - **Space** – Jump
